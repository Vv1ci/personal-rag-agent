# 使用和验收

日常双击“启动知识库.cmd”，保留启动中心窗口。缺依赖时运行安装依赖脚本，缺模型时点击初始化模型；这些不必每次重复。

1. 上传 examples/acceptance.txt，问“蓝鲸档案的项目编号和预算是什么？”预期 BW-7391、137 元，并显示来源。
2. 重传相同内容，预期跳过重复索引。
3. 同名文件改预算为 286 元后上传；新建对话或关闭记忆，再问同一问题并检查下载原文件。
4. 删除测试文件，新建对话后确认检索来源消失。
5. 停止再启动，其他文档仍应保留。

更新/删除验收要用新对话，避免旧信息来自会话记忆。

缺少 Ollama 时先安装；端口占用时关闭以前手动启动的 API/Streamlit。其他启动失败查看 logs/launcher-api.log、launcher-ui.log、launcher-check.log。分享日志前请去除个人路径和问题内容。
